# 🛒 Alışveriş Listesi Uygulaması

Node.js ve Express kullanılarak yapılmış giriş-çıkış ve liste ekleme/silme özellikli basit bir alışveriş listesi uygulamasıdır.

---

## 🚀 Özellikler

- Basit giriş sistemi (demo kullanıcı)
- Listeye ürün ekleme
- Ürün silme
- Checkbox ile işaretleme (üstü çizili gösterim)
- Çıkış yapma özelliği

---

## 🛠️ Kullanılan Teknolojiler

1. Node.js
2. Express.js
3. EJS
4. Bootstrap 5
5. FontAwesome

---

## ⚙️ Kurulum ve Çalıştırma


npm install express ejs
node index.js

Tarayıcıda aç:

[medium](http://localhost:3000)
